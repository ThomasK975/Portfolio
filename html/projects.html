Self-Hosted Linux Server

Personal

2026

  • Turned an old Lenovo laptop into an always-on Ubuntu home server that hosts my own projects, including Minecraft servers and my Discord bot.
  • Wrote systemd services so each server starts on boot, restarts after a crash and shuts down cleanly.
  • Secured remote access with SSH key-only login, and put the game server behind TCPShield with a custom domain to hide my home IP and protect against DDoS attacks.

Spawn Management Plugin

Personal

Minecraft server plugin

  • Lets server admins set, teleport to and delete spawn points separately for the Overworld, Nether and End.
  • Includes a chest-style GUI menu for choosing a dimension, tab completion and permission-based access control.
  • A configurable teleport countdown cancels if the player moves, with pending teleports tracked per player so overlapping requests don't clash.
